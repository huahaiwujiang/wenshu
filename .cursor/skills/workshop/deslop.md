# 文枢贴图/成稿 · 去 AI 味（新媒体改编）

> 借鉴自 `web-novelist` 的 `story-deslop`：改味不改内容、改最少、自检后再交付。  
> **不照搬网文规则**：不写「Show Don't Tell / 章末命运升华 / 眼中闪过」那套小说技法。  
> 本文件服务公众号长文、小红书、口播等**信息向文案**。贴图模式只出图，不去配文。

## 何时执行

`/workshop` **写完 IR 落盘后、CLI 渲染前**，必须对本轮 IR 的可读字段做一遍去 AI（见 SKILL 标准流程）。  
用户显式说「不去 AI / 保留草稿腔」时可跳过，并在汇报里注明。

扫描字段：`title`、`digest`、`hooks.opening`、`hooks.closing`、`sections.*.heading`、`sections.*.paragraphs`、`xhsBeats`、`scriptBeats`。  
不改：`sources` 里的原文摘录、版本号、官方链接、专有名词、真实数据。

## 核心原则（从 story-deslop 迁移）

1. **改味，不改正文事实**：只动「怎么说」，不增删素材里没有的信息点。
2. **改最少**：能换词就不整句重写；没有问题的句子原样保留。
3. **删空话优先于堆修辞**：解释尾巴、口号升华，优先删或压成具体信息。

## Gate 速查（新媒体 6 门）

| Gate | 查什么 | 典型命中 | 修法 |
|------|--------|----------|------|
| A 套话/禁用词 | 新媒体 AI 口头禅 | 「不是小修小补」「扫一眼」「隐性亮点」「写进 Release 前排」「X 条线一起推」 | 删或改成具体事实 |
| B 句式套路 | 先否后肯、假对仗、冒号堆砌 | 「不是 A，而是 B」；「既…又…更…」连排；破折号/省略号装节奏 | 直接写后项；拆成完整自然句 |
| C 自指点评 | 作者替读者划重点 | 「这版把…」「值得一提」「不难看出」「总的来说」 | 删点评，留事实与读者利益 |
| D 电报体/提纲腔 | 缺主语、碎句连排 | 「导航可跳。发图更稳。SQLite 移除。」 | 补成有主谓宾的完整话 |
| E 空话推卸 | 把信息推给图/链接 | 「条目见图」「图里说清了」「详见上图」「两张图够用」 | 补进具体信息点 |
| F 口号升华 | 空喊收束 | 「开启新篇章」「值得每个开发者关注」「赋能未来」 | 改成谁该升/注意什么/下一步 |

## 禁用词与句式（信息向）

**出现即改：**

- 不是小修小补 / 全方位升级 / 重磅更新（无依据时）
- 扫一眼 / 一文看懂 / 干货满满 / 建议收藏
- 隐性亮点 / 写进前排 / N 条线一起推
- 这版把… / 值得一提 / 不得不说 / 总的来说 / 不难看出 / 由此可见
- 赋能 / 打造闭环 / 开启新篇章 / 助力每一位…
- 「条目见图」「如图所示」「图里已经写了」

**标点：** 正文少用破折号 `——`/`—` 和省略号 `……` 装节奏；停顿用句号、逗号或拆句。版本号、代码、URL 中的符号除外。

**引号：** 不给普通词加「强调引号」（所谓的「体验」、完成「蜕变」）。专有名词、命令名、接口名、需要逐字引用的原文可保留。

## 改写对照

| AI 腔 | 更自然 |
|-------|--------|
| 这版把长会话体验又推了一截 | 长会话右侧导航现在能跳到尚未载入的轮次 |
| 不是小修小补，而是一次体验升级 | （删前半）日常卡点修了一轮：导航、发图、误判断线 |
| 值得一提的是 SQLite 后端也调整了 | 可选 SQLite Session 后端已移除，升级前请用旧版导出 |
| 条目见图，两张图够用 | （删）补写该图对应的 2 个具体信息点 |
| 建议每个关心 AI 编程的朋友都看一看 | 跑长会话或运行中发图的，可以优先升；仍用 SQLite 的先导出 |

## 执行步骤（Agent）

1. 通读 IR 可读字段，按 Gate A→F 标记命中。
2. **能删就删**空话；会丢信息的句子改为「降 AI 重写」，不得整段清空到只剩分类名。
3. 写回同一 `output/article/{slug}.json`，再跑 CLI 渲染（贴图模式不跑 CLI）。
4. 汇报时可一句带过「已去 AI」，不必贴长报告；重度命中才列 1～3 条改了什么。

## 明确不做

- 不引入网文的情绪外化、章末命运腔、微动作复读规则。
- 不把技术名词口语化到失真（`read_image`、SQLite、HMR 等保留）。
- 不为「更像人」而注水、加错字、或编造素材没有的结论。

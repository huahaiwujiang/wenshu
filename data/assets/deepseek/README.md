# DeepSeek

写 DeepSeek 相关文章 / 贴图时用本夹文件，**不要现画 logo、不要用错误色块代替鲸鱼**。

本夹属于资源库 [`data/assets/`](../README.md)，成品图仍输出到 `output/wechat-images/YYYY-MM-DD/`（见贴图规则）。

## logo/

| 文件 | 用途 |
|------|------|
| `whale.svg` | 官方蓝色鲸鱼（仅图标）。圆标、顶栏小图标：蓝底白鲸，或原色 `#4D6BFE` |
| `wordmark.svg` | 官方横版（鲸鱼 + deepseek 字标） |

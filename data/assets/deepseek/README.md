# DeepSeek

写 DeepSeek 相关文章 / 贴图时用本夹文件，**不要现画 logo、不要用错误色块代替鲸鱼**。

本夹属于资源库 [`data/assets/`](../README.md)，成品图仍输出到 `output/wechat-images/YYYY-MM-DD/`（见贴图规则）。

## logo/

| 文件 | 用途 |
|------|------|
| `whale.svg` | 官方蓝色鲸鱼（仅图标）。圆标、顶栏小图标：蓝底白鲸，或原色 `#4D6BFE` |
| `wordmark.svg` | 官方横版（鲸鱼 + deepseek 字标） |

## niang/（社区 DeepSeek 娘，透明底 PNG）

| 文件 | 用途 |
|------|------|
| `standing.png` | 全身立绘，海报主视觉 |
| `bust.png` | 半身，头图 / 侧栏 |
| `q-stand.png` | Q 版站立，贴纸、小卡 |
| `q-wave.png` | Q 版挥手，欢迎 / 收束图 |

特征：蓝发、鲸鳍耳、呆毛、深蓝女仆装、白围裙、鲸尾。

## 注意

- 官方 logo 为 DeepSeek 商标，仅用于介绍其产品的配图。
- 娘化形象参考社区 Whale-chan / 鲸鱼娘（原型「溟月」为 CC BY-NC-SA），非官方吉祥物；非商用、勿当官方人设。
